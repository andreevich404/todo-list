# To-Do List — лабораторная работа №9

Приложение на Vue 3, TypeScript и Vite: задачи пользователей, поиск, редактирование
в модальном окне, выполненные задачи, светлая и тёмная темы. Pinia и
`pinia-plugin-persistedstate` сохраняют состояние в `localStorage`, Vue Router
предоставляет страницы входа, регистрации, задач и About.

- ФИО: Толкачев Иван Андреевич
- Группа: ФИТ-241
- Node.js: **v24.22.0**
- [Опубликованное приложение](https://andreevich404.github.io/todo-list/)

## Установка и команды

```sh
npm ci                # установка по package-lock.json
npm run dev           # сервер разработки
npm run type-check    # типы приложения, шаблонов Vue и конфигурации Vite
npm run lint          # ESLint без ошибок и предупреждений
npm run lint:fix      # явное автоисправление ESLint
npm run format        # явное форматирование Prettier
npm run format:check  # проверка форматирования
npm run check         # типы, ESLint, Prettier без изменения файлов
npm test              # тесты сторов, маршрутов и восстановления данных
npm run build         # check, затем сборка Vite в dist/
npm run preview       # локальный просмотр сборки
```

`vue-tsc` проверяет TypeScript и выражения в Vue-шаблонах, `tsc` — конфигурацию
Vite. Vite собирает приложение для браузера и самостоятельно типы не проверяет.
При ошибке типов, линтера или форматирования `build` останавливается до сборки.

## Сохранение данных и проверка

Формат лабы №7 сохранён: `todo.users` содержит `users` и `currentUserId`,
`todo.store` — `tasks` и `nextId`, ключ `theme` — тему. После восстановления
сторы проверяют записи и отбрасывают повреждённые. Авторизация учебная,
без сервера; используйте вымышленные адреса и пароли.

1. До обновления приложения в версии лабы №7 зарегистрируйте `ivan@example.com`
   с учебным паролем `secret1`. Войдите, добавьте две задачи, отметьте одну
   выполненной и включите тёмную тему.
2. После обновления откройте приложение в том же браузере и на том же адресе,
   не очищая `localStorage`. Вход, задачи, отметка выполнения и тема сохраняются.
   Перезагрузите страницу — данные остаются.
3. Добавьте, переименуйте и удалите задачу, проверьте поиск. Откройте модалку
   клавиатурой, закройте по Esc — фокус возвращается к кнопке вызова.
4. Выйдите. Прямая ссылка `/#/todo` перенаправляет на вход, включая перезагрузку.
   `/#/about` доступна гостю. Регистрация и вход доступны по `/#/register`
   и `/#/login`.
5. Зарегистрируйте `petr@example.com`, войдите: задач Ивана нет. Добавьте свою
   задачу, выйдите и снова войдите как Иван — видны только его задачи.
6. Проверьте ошибки: неверный email, короткий пароль, разные подтверждения,
   повторный email и неправильный пароль. Ошибки отображаются у формы.
7. Проверьте узкий экран, навигацию Tab, видимый фокус, подписи полей и кнопок,
   обе темы. Выполненные задачи зачёркнуты и расположены после невыполненных.

## Структура и публикация

`src/components/` — компоненты, `src/pages/` — страницы, `src/stores/` — Pinia,
`src/router/` — маршруты и guard, `src/types/` — общие модели,
`src/utils/` — вспомогательные функции. Тесты находятся в `tests/`, стили — в `scss/`.

GitHub Actions выполняет установку, тесты и `npm run build`, затем публикует
`dist/` в GitHub Pages. Hash-маршруты позволяют открывать страницы напрямую
и перезагружать их без серверных перенаправлений.
