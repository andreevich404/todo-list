# todo-list

Приложение To-Do List (лабораторная работа №4, задание 2): список задач на **Tailwind CSS v4** и vanilla JS с упором на доступность.

Это Tailwind-версия (ветка `lab-4-tailwind`). Версия на Sass находится в ветке `lab-4`. Интерфейс и поведение совпадают; стилизация выполнена только утилитами Tailwind, собственных CSS-правил нет (`src/input.css` содержит лишь подключение Tailwind и вариант `dark`).

## Возможности

- добавление, редактирование и удаление задач через нативное модальное окно `<dialog>`;
- отметка выполнения: выполненные задачи зачёркиваются, получают галочку и уходят вниз списка;
- поиск по названию с фильтрацией по мере ввода;
- светлая и тёмная темы (`dark:` через `data-theme="dark"` на `<html>`, выбор сохраняется, при первом визите учитывается `prefers-color-scheme`);
- хранение в `localStorage` (`todo.tasks`); пустое или повреждённое хранилище не ломает запуск;
- адаптивная вёрстка (mobile-first, брейкпоинты 480 / 768), отключение анимаций при `prefers-reduced-motion` (`motion-reduce:`);
- озвучивание действий через `aria-live` («Задача добавлена», «Найдено задач: N»).

## Установка и запуск

```bash
npm install
```

Сборка стилей (результат в `dist/css/main.css`):

```bash
npm run build
```

Разработка (два процесса в разных терминалах):

```bash
npm run tailwind:dev
npx serve .
```

Страницу нужно открывать через локальный сервер, а не как файл. Tailwind подключён через npm (`tailwindcss` и `@tailwindcss/cli`), Play CDN не используется. Классы Tailwind находит в `index.html` и `js/main.js`, поэтому имена классов пишутся целиком.

## Структура

```
src/input.css    подключение Tailwind и вариант dark
js/main.js       логика приложения (хуки через data-* и js-* классы)
index.html       разметка со стилизующими утилитами
dist/            собранный CSS (не в git)
```

## Доступность

- нативные `<button>`, `<input>`, `<dialog>`, `<label>`; порядок Tab совпадает с порядком в DOM, `tabindex` не используется;
- кнопки-иконки называются вместе с задачей через `aria-labelledby`: «Удалить задачу Купить молоко»; имя обновляется при переименовании;
- в модальном окне фокус попадает в поле названия, Esc закрывает окно, при закрытии фокус возвращается на кнопку-инициатор;
- после удаления фокус переходит на ближайшую видимую задачу (с учётом поиска) или на кнопку «Добавить задачу»;
- видимый `focus-visible:` у всех интерактивных элементов, контраст текста не ниже 4.5:1 в обеих темах, выполненная задача отличается зачёркиванием и галочкой, а не только цветом.

Как проверять:

1. Пройти все сценарии только клавиатурой (Tab, Shift+Tab, Enter, Space, Esc).
2. Chrome DevTools -> Lighthouse -> Mode: Snapshot, Categories: Accessibility (Desktop и Mobile, обе темы; снять галочку Clear storage).
3. DevTools -> Elements -> Accessibility -> Computed Properties -> Name для кнопок задач.
